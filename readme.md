I am and have always been interested in Greek Mythology, I am also interested in genealogy.
A long time ago I made a microsoft access database of many characters of ancient Greek Mythos.
Recently I got AI to structure a web based application around that data, and with my direction it created something
I'm very impressed with and, at my behest, it is rapidly adding cool features like the kinship finder.

I intend to put more work into this, there are errors and a lot missing right now, new features might also be cool.
But I thought I might as well make it a public repo, half of the idea of getting AI to turn it into a webpage was with
the potential idea of putting it on github pages where others could play around with it too.
